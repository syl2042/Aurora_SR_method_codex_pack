# Mobile B2B Design Skill

Use this reference for responsive-first apps, mobile companion apps, and compact workflows such as Nexus Pocket.

## Design objective

Mobile B2B must be fast, readable, and action-oriented. It should not simply shrink a desktop cockpit.

## Rules

- Prefer one main task per screen.
- Use compact page headers with clear current context.
- Avoid wide tables; use cards, grouped lists, or progressive disclosure.
- Keep primary actions reachable.
- Use drawers/sheets sparingly and keep them focused.
- Make empty/loading/error states concise and useful.
- Avoid dense multi-column layouts below tablet width.
- Preserve theme behavior.

## Common patterns

- Inbox/list of work objects.
- Detail page with sticky action area if needed.
- Quick capture form.
- Search/filter sheet.
- Source or note card.
- AI answer with citations and evidence collapsed by default.

## Codex guidance

Ask Codex to implement responsive behavior explicitly:

- mobile layout;
- tablet layout;
- desktop layout;
- long-content behavior;
- keyboard/focus behavior;
- touch target size.
